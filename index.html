    Week # Vehicles # Partners Total Events Invalid Valid Avg alerts/hr (Total) Avg alerts/hr (Invalid) Daily Alert Threshold % Vehicles Exceeding Daily Threshold
    ℹ️ Column Definitions
    Week
    ISO calendar week and date range covered.
    # Vehicles
    Distinct vehicles (assets) that had at least one fatigue alert this week.
    # Partners
    Distinct fleet/partner organizations represented this week.
    Total Events
    All fatigue alerts regardless of confirmation status (Criteria Not Met + Verified). Click to drill down.
    Invalid
    Fatigue alerts confirmed as "Criteria Not Met" — the system fired but the driver was not actually fatigued. These still cause an in-cab distraction. Click to drill down.
    Valid
    Fatigue - Microsleep or Drowsiness alerts confirmed as "Verified" — genuine fatigue events. Click to drill down.
    Avg alerts/hr (Total)
    Average across all vehicles of each vehicle's single worst 60-minute rolling window of total alerts for the week. Reflects overall in-cab notification burden.
    Avg alerts/hr (Invalid)
    Average across all vehicles of each vehicle's single worst 60-minute rolling window of invalid-only (Criteria Not Met) alerts. Reflects avoidable driver distraction.
    Daily Alert Threshold
    The daily alert count threshold currently set by the user. A vehicle is considered "impacted" if it exceeded this number on any single day. Lowering this value sets a stricter standard, which will raise the % Vehicles Exceeding Daily Threshold.
    % Vehicles Exceeding Daily Threshold
    Percentage of vehicles that exceeded the daily alert threshold on at least one day this week. A higher % means more of the fleet was over-alerted. Because drivers receive in-cab notifications for ALL fatigue events (valid and invalid), this metric captures total driver distraction burden. Lowering the threshold raises this % because the standard becomes stricter.

    Note on Daily Alert Threshold & % Vehicles Exceeding Daily Threshold: Drivers receive an in-cab notification for every fatigue alert — valid or invalid. The "Daily Alert Threshold" input sets the maximum acceptable daily alert count. Lowering this threshold applies a stricter standard: more vehicles will appear as "impacted" because fewer alerts per day are considered acceptable. This is expected behavior — use a lower threshold when the goal is to minimize driver distraction.
